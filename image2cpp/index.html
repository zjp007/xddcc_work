image2cpp

image2cpp 是一个将图片转换为字节数组（或将数组转换回图片）的简单工具，用于 Arduino 或 Raspberry Pi 上的 OLED 等（单色）显示屏。
它最初是为了与 Adafruit OLED 库配合使用而制作的（您可以在此处找到 Arduino 的示例草图），但已被社区扩展到可用于各种（嵌入式）项目。

更多信息（和致谢）可以在 Github 仓库 中找到。您也可以在这里报告您可能遇到的任何问题 (issues)。

您觉得这个工具有用吗？欢迎在 Github 上支持我的开源软件，特别是用于商业用途时。
